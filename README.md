## 🌐 1-Click Deployment to Replit

This project is fully configured for **Replit** (Core or higher):

1. **Import to Replit**:
   - Go to [Replit.com](https://replit.com) and click **Create Repl** -> **Import from GitHub** (or drag and drop this `visual-resume` folder).
2. **One-Click Run**:
   - The included `.replit` and `replit.nix` files will automatically configure the Node.js 20 environment.
   - Click the green **Run** button at the top.
3. **Live Public URL**:
   - Replit will automatically open the webview and give you a permanent live public URL (e.g. `https://your-repl-name.username.repl.co`).

### Running Locally
```bash
# Navigate to the visual-resume folder
cd visual-resume

# Install dependencies
npm install

# Start the server
npm start
```
Open **`http://localhost:3000`** in your browser.
